# 💼 MERN Stack Job Portal

A full-stack Job Portal web application built using the MERN Stack. 
This platform allows students to search and apply for jobs, while recruiters can register companies, post job openings, 
and manage applicants through an interactive dashboard.

---

## 🚀 Features

### 👨‍🎓 Student
- User Registration & Login
- JWT Authentication
- Update Profile
- Upload Resume (Cloudinary)
- Search & Filter Jobs
- Apply for Jobs
- View Applied Jobs
- Responsive UI

### 🏢 Recruiter
- Recruiter Registration & Login
- Add New Company
- Update Company Details
- Upload Company Logo
- Create Job Posts
- Manage Posted Jobs
- View Applicants

## 🌐 Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=8000

MONGO_URI=your_mongodb_connection_string

SECRET_KEY=your_secret_key

CLOUD_NAME=your_cloudinary_name

API_KEY=your_cloudinary_api_key

API_SECRET=your_cloudinary_api_secret
```
